# Admin Panel

Admin dashboard for an online store: categories, products (with attributes, colours, guarantees and brands), CRUD through a REST API, paginated searchable tables and a CKEditor description field.

پنل مدیریت فروشگاه اینترنتی: دسته‌بندی، محصول، ویژگی، رنگ، گارانتی و برند.

**Live:** http://admin-panel-lime-one.vercel.app/

## Stack
React · React Router · Redux Toolkit · Formik + Yup · axios · CKEditor 5 · Chart.js · SweetAlert2 · Bootstrap / Tailwind CSS

## Run
```bash
npm install
npm run dev
```
